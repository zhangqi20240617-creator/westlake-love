# 同桌与座位轮换系统 (Desk-mate System) GDD

## 1. 核心机制设计

### 1.1 座位轮换 (Seating Rotations)
- **触发时机**：每次游戏开局（初一开学），以及每次**期中考试**、**期末考试**出成绩之后。
- **轮换算法**：
  - 系统随机或带权重地从“可分配同桌池”中抽选一位成为 `GameManager.current_deskmate`。
  - **权重机制**：如果某位女主角好感度极高（>80），则成为同桌的概率大幅提升至 30%；如果处于“冷战”，则概率降为 0%。

### 1.2 可分配同桌池
为丰富日常生态，同桌不仅限于女主角，加入经典泛用型 NPC：
1. **苏晚晴 / 余小桐 / 林晓雨**：女主角，与其同桌可直接触发心跳互动。
2. **“睡神”胖子同学**：泛用男，总是上课睡觉。
3. **“内卷”学霸女生**：泛用女，笔记借你抄，但极其讨厌你上课发出声音。
4. **“百事通”调皮鬼**：泛用男，八卦极多，且手里经常有零食。

## 2. 交互体验设计

### 2.1 日常课堂互动增强 (Events)
将原本 `events_daily.json` 中单调的上课内容，扩展出“同桌专属高优事件”的拦截。
- 当处于 `location: classroom` 并且 `slotId: morning/afternoon` 时，会以特定概率触发**同桌特殊剧情**：
  - **传纸条**（与晚晴）：上课铃响后，突然一张叠成千纸鹤的纸条推到你手边。
  - **偷吃零食**（与调皮鬼）：对方在抽屉里撕开包装袋的声音嘎吱作响，分了你半包辣条（+2压力缓解，-1学习）。
  - **掩护睡觉**（与睡神）：老师突然点名，你赶紧踢了胖子一脚。

### 2.2 抄作业系统 (Copying Homework)
- 特殊行动扩展：如果在晚自习或早上来到教室（`hw_status = 1`），如果同桌是“学霸”或“女主角”，解锁特殊选项【求救借作业抄】。
- 借作业抄可以直接将状态置为 `hw_status = 2` (免除老师责骂)，但在下一次考试中，该科目的隐藏复习熟练度会不升反降。

## 3. 技术落地方案

1. **`GameManager.gd`**
   - 增加 `var current_deskmate: String = "none"`
   - 增加 `func refresh_deskmate()`
2. **`MainGame.gd`** / **`ExamManager.gd`**
   - 在考试（期中/期末）结束的回调 `_on_score_reveal_finished` 中调用 `refresh_deskmate()`，并发出 Toast/日志提示“大换座了，你的新同桌是...”。
3. **数据层注入 (`events_life.json`)**
   - 新增 6 个同桌专属触发事件 (ID 以 `deskmate_` 打头)。
   - 利用 `requireFlags` 或特定条件，限定条件为 `GameManager.current_deskmate == "xxx"` 才可以抽取。
