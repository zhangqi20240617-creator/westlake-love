# 毕业旅行 (Graduation Trip System)

## 1. 核心定位与前置条件
毕业旅行是中考结束后、最终结局揭晓前（Day 570之后的延展阶段）最后一次倾泻资源和好感度的**史诗级谢幕**。
- **触发节点**：大考出分 (`score_reveal_ui` 关闭) 之后，不要直接切入干巴巴的结局文本，而是跳转到一个名为“毕业季的抉择 (`grad_trip_choice`)”的过渡事件。
- **资金门槛**：毕业旅行不是免费的，需要消耗长年累积的 `money` (比如 1000 - 3000 不等)。
- **羁绊要求**：只能邀请好感度突破极致 (>80) 的女主角。

## 2. 差分路线与特殊CG反馈
通过修改主线结算引擎，玩家可以根据手头的金币与攻略对象，选择不同的路线（通过选项的 `requireStats: {"money": 3000}` 来过滤）：

### Route A: 豪华出国游 / 海岛度假 (需极高金钱)
- 体验：在阳光沙滩或异国街头与她牵手。
- 结局加权：这会在最终结局结算前，提供一个极端的魅力/情商加权，并可能解锁一个独特的【完美恋人】分支结局评价，同时附带专属豪华长文本。

### Route B: 穷游 / 绿皮火车 (低配但纯爱)
- 体验：没多少钱，只能买两张坐票去隔壁省看海。虽然辛苦，但能在绿皮火车上依靠在彼此肩头。
- 结局加权：虽然穷，但是极其考验基础好感点数，会触发更催泪走心的纯爱长文本。

### Route C: 孤独游 / 打工仔 (好感度不足 或 选择不浪)
- 若没能把任一女孩追到满级，或者想为了高中学费攒钱而放弃旅行。
- 体验：看着同学们在朋友圈晒合照，你独自骑着单车环绕一圈西湖，迎接收束的宁静。

## 3. 技术落点
- **入口改写**：修改 `MainGame.gd` 中的 `_on_score_reveal_finished()`。原先它直接调用 `ending_screen.trigger_ending()`，现在我们将它改为先加载 `DialogueUI` 播放一场巨大的 `event_grad_trip`。
- **结局对接**：在 `events_grad_trip.json` 的最后一页跑完时，通过新注册的回调或特殊的 `logicType` ("grad_trip_ended")，无缝连入原本的 `EndingScreen` 系统，并将旅途产生的属性变化带入高校录取判定中！
